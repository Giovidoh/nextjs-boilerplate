# LESSONS

| Date       | What went wrong                 | Rule to apply                          |
|------------|---------------------------------|----------------------------------------|
| 2026-11-18 | Configs were written for Next 16 (eslint flat import, tsconfig `.next/dev/types`, README) while `next` was pinned to 15.5.7 → `eslint` crashed and `next build` silently skipped linting | Keep `next`, `eslint-config-next` and configs on the same major; run `pnpm lint` on its own, never trust the build to lint |
| 2026-11-18 | Components hardcoded colors/sizes (`bg-white`, `#BCBABA`, `text-[clamp(...)]`) → every new design meant editing each component | Components only consume design tokens (CSS variables); brand values live in `styles/theme.css` only. Since 2026-11-18 tokens are applied in the design-system layer (`components/<category>`), never in `components/ui` |
| 2026-11-18 | `QueryClient` instantiated at module scope in a client provider → cache shared across SSR requests | Create the QueryClient per request on the server and once per browser session (`getQueryClient` pattern) |
| 2026-11-18 | Making `[locale]` pages static (generateStaticParams) broke the build: client pages called `useSearchParams()` without a Suspense boundary | Read `searchParams` in the server page (`await props.searchParams`) and pass values down; reserve `useSearchParams` for client islands wrapped in `<Suspense>` |
| 2026-11-18 | Tried to stop a local server with `taskkill /IM node.exe` (would kill every Node process on the machine) | Run servers through the preview tool (`.claude/launch.json`) and stop them with `preview_stop` |
| 2026-11-18 | Piped `yes y` into `shadcn add`: it silently approved overwriting already-customized primitives (button, input, textarea lost their token classes) | Never auto-answer `shadcn add` with piped input. Since `components/ui` is now kept identical to the CLI output, `--overwrite` is safe; customizations belong in `components/<category>` |
| 2026-11-18 | Base UI `Progress` formatted `aria-valuetext` with the runtime locale → "60%" on the server vs "60 %" in a French browser → hydration error | Primitives that format numbers (Progress, Meter, Slider, NumberField) get `locale` from next-intl's `useLocale()` by default |
| 2026-11-18 | After editing a shared component, `next dev` kept serving a stale server bundle (lazy server HMR) → misleading hydration mismatch | When a hydration diff shows old markup, restart the dev server and recheck in a fresh tab before debugging |
| 2026-11-18 | Built Tailwind classes dynamically (`text-${size}`) in the UI kit → classes never generated | Only use complete literal class names; map variants to full strings |
| 2026-11-18 | Wrote `proxy.ts` through a bash heredoc: this shell collapsed `\.` to `\.` in the matcher string, so the regex excluded almost every path and `/login` returned 404 instead of redirecting to `/fr/login` | Write files containing backslashes with the Write/Edit tools, never via shell heredocs here; smoke-test an unprefixed URL (`/login` → 307) |
| 2026-11-18 | During a cherry-pick, a Write to a conflicted file failed (file not re-read) but the chained `git add` + `cherry-pick --continue` still ran → conflict markers committed on `next-15` (fixed with a fixup + autosquash before any push) | Never chain `git add` after an edit in the same step; before `--continue`, run `git grep -nE "^(<<<<<<<\|>>>>>>>)"` and only continue on zero hits |
