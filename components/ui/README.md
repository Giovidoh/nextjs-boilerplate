# components/ui — third-party code

Generated by the shadcn CLI (style `base-nova`, Base UI). **Do not edit these files.**

- Customizations (design tokens, variants, default props, i18n) live in the design system: `components/actions`, `forms`, `feedback`, `overlays`, `display`, `common`.
- Only `components/*` may import from here; the app and features import the design system (ESLint `no-restricted-imports`).
- Update or restore a component at any time:

  ```bash
  pnpm dlx shadcn@latest add <component> --overwrite
  ```

- Add a new one, then create its design-system entry point (`components/<category>/<component>.tsx`).
